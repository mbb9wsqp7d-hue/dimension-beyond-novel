# 《维度之外》小说数据库

> 笔名：枕云
> 状态：V1.0 数据库初始化
> 原则：GitHub 中的“现行设定”作为后续创作的唯一真值源；旧设定保留但不得覆盖现行设定。

## 三部曲
1. 第一部《众生游戏》——易小星——选择
2. 第二部《时墟》——陆辰 / L-Root——存在与尊严
3. 第三部《超维之域》——林凡——自由

## 核心母题
一个虚构的人 → 一群数据生命 → 一个真实文明
选择 → 存在 → 自由

- 00_总控：母档、版本、时间线、冲突表
- 01_世界观：无名之域、维度、沙盘宇宙
- 02_人物：角色唯一人物卡
- 03_文明：九大文明
- 04_Ω协议：Ω协议、九大核心
- 05_第一部_众生游戏
- 06_第二部_时墟

## 创作规则
世界观必须通过人物行动、冲突、代价和选择进入故事；不得用大段设定说明代替剧情。
