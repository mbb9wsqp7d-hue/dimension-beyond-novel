# 残片体系历史设定总索引

> 本档专门保存此前讨论过的“碎屑—残片—核心—Ω协议”体系。由于历史版本很多，本档不擅自统一名称；不同版本并列保存，供后续重构时裁决。

## 一、最稳定的分层逻辑

历史讨论中反复出现的基础链条：

**碎屑 → 残片 → 核心 → Ω协议**

曾使用的类比：
- 核心 = 宇宙DNA的大基因/完整位点
- 残片 = 稳定规则片段/基因片段
- 碎屑 = 最小数据构件/碱基
- Ω协议 = 九大核心完成闭环后的宇宙自洽结构

另一个重要版本：
- 碎屑：一次实验、失败、战斗、意识波动产生的最小数据
- 残片：经过多次验证后可稳定调用的规则
- 核心：文明级/宇宙级完整规则位点

## 二、残片曾承担过的剧情功能

### 1. 系统采集
第一卷早期设计不是传统“打怪掉装备”，而是宿主在修炼、实验、事故、失败中产生数据，系统进行采样与入档。

重要原则：
**失败也是数据。**
失败、事故、突变、走火、暴走等可以反向定义规则边界。

### 2. 文明硬通货
另一阶段设定中：
**残片是唯一硬通货。每一次文明交锋 = 对规则资源的掠夺与守护。**

残片不只是能源，而是“规则所有权”：
残片 → 规则 → 宇宙运行条款。
文明掌握越多残片，就越能影响宇宙未来。

### 3. 文明战争驱动力
历史方案：
- 修真 × 科技争夺秩序类残片
- 魔法 × 机械争夺时间/空间类残片
- 虫族 × 魔界争夺混沌/熵能类残片
- 所有文明最终觊觎真理残片

因此文明战争不只是阵营冲突，而是资源、规则、理念三层同时冲突。

## 三、历史九核版本A

曾使用：
1. 秩序
2. 能量
3. 时间
4. 混沌
5. 命运
6. 力量
7. 虚空
8. 灵识
9. 灵魂

其中：
- 混沌 = 突变、演化、不确定
- 力量 = 爆发、承载、对抗
- 虚空 = 空间、黑洞、维度裂隙
- 灵魂 = 死亡、轮回、记忆传承

## 四、历史九核版本B

另一版本曾出现：
秩序、能量、时间、生机、死寂、命运、灵识、力量等组合。

其中“死寂核心”：
- 象征：熵、消亡、归零
- 碎屑：衰败曲线、熵能炮数据、灵魂燃烧
- 残片：验证极限与失败边界
- 功能：清除无效结构、回收宇宙垃圾数据

当前母档采用：

4. 空间
5. 生机
6. 灵识

旧版“混沌/力量/虚空/灵魂/死寂”不删除，其功能可拆分迁移到现行九核。

## 六、残片细化方法

历史讨论中曾把单一核心继续拆成：

**核心 → 三大母规则 → 九个次级规则残片 → 基础碎屑**

例如秩序核心曾拆出：
- 能量守恒
- 因果律
- 对称律

再继续分裂为更具体规则。

这种方法非常适合未来建立“残片数据库”，因为每个残片都可以绑定：
来源文明、首次出现、获得者、功能、代价、转手过程、最终归属。

## 七、灵识残片旧设定

碎屑来源：
- 脑机数据
- 灵魂碎影
- 群体共鸣
- 吟唱合拍

残片作用：
- 意识耦合
- 精神共振
- 记忆移植

核心方向：
让文明从被动进化转向主动自我认知与选择。

旧版曾把它与第四墙绑定；现行版应去掉第四墙解释，但“自我认知与主体性”可完整保留。

## 八、熵能残片旧设定

分层：
碎屑（过热/磨损） → 残片（熵蚀场/腐化传播） → 核心（全域熵预算与极限）。

曾定义三条规则：
- 增律
- 扩散律
- 交换律

采集场景：
机械义体过热、炼金残渣、魔界熵蚀等。

注意：现行世界观中熵能可以作为规则之一，但不能解释“宇宙为什么存在”。

## 九、真理残片旧设定

定位曾是：
所有规则的可证明性、一致性与最小描述。

曾定义：
- 一致律
- 最简律
- 可证律

重要采集例：
“呼吸稳场 = 时钟同步 = 合唱节拍”的跨文明同构。

历史后期曾把真理残片写成“章节重写权/第四墙权限”，这一部分已经废弃。

现行可保留：
**真理不是最高攻击力，而是验证不同文明表象背后是否存在同一底层规律。**

## 十、第一部残片成长节奏旧案

曾规划：
- 卷一：碎屑采集
- 卷二：残片对抗
- 卷三：核心整合

第一卷201—300章曾设：
碎屑 → 跨文明融合成残片 → 残片聚合为核心雏形 → 九大核心协议开始显现。

旧系统提示：
【九大核心协议雏形已解锁1/9】

## 十一、文明与残片旧关系

历史资料中曾使用：
- 修真：永生/超脱，偏生机、命运、时间
- 科技：秩序/掌控，偏秩序、能量、空间
- 魔法：多元/自由，偏能量、空间、灵识
- 机械：效率/替代，偏秩序、熵能、力量
- 虫族：生存/繁殖，偏生机、混沌
- 灵界：灵魂/记忆，偏灵识、时间
- 魔界：代价/熵化，偏命运、熵能
- 星空巨兽：原初/自然力，偏力量、虚空
- 旧超维文明：真理/重写【现行需重构】

## 十二、未来数据库字段

后续每一个重要残片建议独立建立记录：

| 字段 | 内容 |
|---|---|
| 残片ID | 唯一编号 |
| 名称 | 残片名称 |
| 所属核心 | 九大核心之一 |
| 层级 | 碎屑/残片/核心雏形 |
| 来源文明 | 首次产生文明 |
| 首次事件 | 第一次出现剧情 |
| 当前持有者 | 人物/势力 |
| 功能 | 能做什么 |
| 限制 | 不能做什么 |
| 代价 | 使用成本 |
| 转手记录 | 谁抢夺/继承 |
| 关联伏笔 | 对应伏笔ID |
| 最终归属 | 后期回收 |
| 正史状态 | 现行/待校准/废弃/可改造 |

## 裁决原则

旧残片设定数量很大，不应直接删除或强行合并。

先全部保存，再做三件事：
1. 找出重复概念。
2. 把旧核心功能映射到现行九核。
3. 将真正能产生剧情冲突的残片留下，避免残片沦为纯技能/装备系统。
