# 《维度之外》剧情知识图谱

本目录把小说资料从“文件仓库”升级为“可检索的创作数据库”。

## 核心关系
人物 → 事件 → 时间 → 文明/势力 → Ω核心 → 伏笔 → 回收

## 创作时的查询顺序
1. 查人物：此时角色知道什么、想要什么、与谁冲突。
2. 查事件：该事件的前因、代价、后果。
3. 查时间线：是否与其他事件冲突。
4. 查规则：涉及哪个文明、核心、Ω机制。
5. 查伏笔：本章能埋什么、必须回收什么。
6. 查现行母档：旧资料与新版冲突时，以现行母档裁决。

## 状态标记
- 【现行】：已进入当前正式世界观
- 【待校准】：来自旧资料，尚未决定是否保留
- 【废弃】：保留历史价值，不进入现行正文
- 【伏笔】：已规划但尚未回收
- 【回收】：已经完成闭环

> 原始资料不删除；知识图谱只负责建立关系，不擅自修改原档。
