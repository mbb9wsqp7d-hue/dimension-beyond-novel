# 写作规范库

本目录用于保存《维度之外》长期创作时必须统一执行的语言、叙事与格式规范。

## 数据来源
- `资料原档/设定/写作设定.txt`
- 各卷章纲中已经形成的叙事节奏与系统提示样式

## 使用原则
1. 原档只作为历史素材，不自动等于现行正史。
2. 系统语言、宿主感知、文明回响应保持层次差异。
3. 世界观信息优先通过事件、冲突、选择和后果表达，避免说明书式灌输。
4. 正文创作前先检查人物、机制、时间线和伏笔数据库。
5. 已废弃的第四墙、作者层、读者层叙事不得因旧模板重新进入现行正文。
