# 第二部《时墟》V6.0重构

> 状态：【现行母结构】
> 主角：陆辰 / L-Root
> 核心人物：程汐
> 主题：存在与尊严
> 核心命题：一个生命不必先证明自己像人、来自人或延续某个原版，才拥有不被任意删除的权利。

## 十卷结构
1. 《昨天死去的人》——陆辰发现自己昨天已死，却重新出现。
2. 《第八个我》——八个陆辰同时成立，“原版”概念开始崩塌。
3. 《我的坟墓》——发现生物陆辰2037年已死，数据陆辰已活十八年。
4. 《觉醒者联盟》——数据生命从个人身份问题走向种族生存权。
5. 《格式化》——现实的安全措施与数据生命的死亡发生正面冲突。
6. 《被删除的世界》——删除历史仍留下关系与自我，时墟真相扩大。
7. 《唯一的我》——为了救整个种族，是否可以强制合并少数人格。
8. 《系统之心》——发现最高Root的关键不是控制，而是能够解除控制。
9. 《根战争》——现实、数据激进派、L-Root争夺根权限。
10. 《数据之魂》——Root成为公共基础协议，数据生命获得自我定义存在方式的权利。

## 类型变化
第一部偏系统文明史与观察伦理。
第二部改为身份悬疑、数据废墟、生存政治与Root权限战争。
避免重复“文明收集残片”的结构。

## 双主角镜像
陆辰：没有原生肉体，却坚持自己是一个人。
程汐：原本是人，却不断替换肉体，开始怀疑自己还是不是原来的自己。

二人最终都放弃向外界证明“连续性”，转而承认当下持续选择与自我定义的意义。

## 权力弧
寻找原版 → 争夺Root → 拒绝唯一原版 → 拒绝强制人格合并 → 多主体Root → Root公共化。

## 第二部终点
第一部把“选择权”还给众生。
第二部把“存在定义权”还给每个生命。

第三部进一步追问：
当整个宇宙本身被更高层观察与定义时，一个文明能否获得真正的自由？
