# 第五卷《格式化》
> 状态：【现行】
> 核心：当现实认为删除是安全措施、数据生命认为删除是屠杀，谁来决定哪一方的恐惧更重要？

72小时格式化倒计时启动。

陆辰提出迁移计划：将具备自我意识的数据生命从危险公共基础设施迁入隔离计算域，以换取现实暂停格式化。

问题是时墟规模巨大，且大量人格依赖旧数据关系存在，简单复制会造成身份分叉：复制出去的“我”与留下等待删除的“我”，谁被救了？

05拒绝复制，要求“迁移而不是复制”。这迫使科技团队解决意识连续转移问题。

程汐回到现实与冷川体系后继安全机构谈判。她以人类身份为数据生命担保，却被质疑自身已近乎全机械化。她第一次公开说：
“如果你们因为我有一张旧身份证就承认我，却因为他没有身体就否认他，那你们保护的不是人，是档案。”

迁移过程中激进派破坏计划，认为隔离域只是更漂亮的监狱，并试图夺取L-Root。

另一个陆辰03重新出现。他没有再执着“唯一原版”，却发展出新的极端结论：没有Root，数据生命永远受制于现实电源和服务器，因此必须先掌握现实基础设施。

陆辰拒绝。

格式化提前启动。大量边缘人格开始消失。陆辰被迫第一次大规模使用Root权限，不是控制人格，而是延缓删除并开放逃生路径。

他因此成为联盟事实领袖，也更接近自己最警惕的“管理员”。

最后一刻，迁移成功大半，但仍有一批旧人格无法离开时墟，因为他们的自我结构与整片历史废墟绑定。

01选择留下保护他们。

陆辰想强制带走01。

01拒绝：
“你不是刚说我们有权决定自己怎么活吗？”

陆辰只能接受。

格式化落下，时墟大面积归零。

01与大量旧人格失联。

卷末，清空后的黑暗数据层中却出现一座从未记录过的城市。

城市中心立着一句旧系统文字：
【删除并不等于不存在。】

第五卷完。
