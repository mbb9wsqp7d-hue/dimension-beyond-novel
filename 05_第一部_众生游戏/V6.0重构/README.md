## 创作原则
1. 故事先于设定。世界观必须通过事件、冲突、选择与代价显现。
2. 每卷必须有独立故事目标、具体敌对关系、中段反转、人物代价、卷末高潮。
3. 每一卷的结果必须成为下一卷的原因。
4. 易小星是系统意识核心，不是宿主、玩家。
5. 秦烈等宿主首先是“人”，其次才是文明代表。
6. 碎屑/残片/核心不是普通升级道具，而是众生对未知世界逐渐稳定的定义。
7. 第一部不提前解释最终高维真相；无名之域与观察机制逐层揭露。
8. 旧第四墙、作者/读者层、文本世界机制不得回流现行正史。
9. 第一部终局必须落在“放弃绝对神权，把选择还给众生”。
10. 结尾钩子：【第一位观察者已确认。】

## 历史资料处理
旧卷纲、原始资料、废案均保留，不删除。可回收其中的具体冲突、场景、人物选择和悬念，但旧解释框架不自动成为正史。
