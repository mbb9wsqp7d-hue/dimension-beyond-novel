# 第六卷《文明战争》·完整剧情母稿
> 篇幅：约451—550章
> 状态：【现行】
> 承接：《第五卷_我们不是NPC.md》
> 核心问题：承认对方是生命以后，为什么战争仍会发生？

## 主线
“我们不是NPC”进入现实网络后，现实社会围绕关闭项目、生命权、科研价值、残片战略价值与玩家权益全面分裂。冷川受命控制Ω-17。赵教授意识到真正危险的不再只是玩家，而是现实文明本身对新世界的利益需求。

现实方面要求与众生谈判，却首先遇到代表权问题：秦烈不能代表所有修真者，苏青不能代表整个科技文明，觉醒者甚至没有正式席位。秦烈给出关键回答：“我们没有皇帝。各自说了算。”众生第一次明确表现为多主体，而非一个统一声音。

【残片-001】被证实可以让一个文明的局部规则短暂进入另一世界，残片因此获得跨文明战略价值。

魔法文明经过长期对“命名”的成功、失败和边界验证形成【残片-002】，其深层方向指向“真理”，但本卷不提前正式定义核心归属。现实方面要求共享，魔法议会拒绝。一次秘密复制行动失败并造成双方死亡，矛盾升级。

玩家重新有限接入，但身份发生变化：有人为研究机构、企业、军方工作，有人保护众生，有人追逐残片。狂刀也重新进入。他已经知道本土生命可能真实存在，却仍选择战斗，表明真正战争并不总来自“不知道对方是人”。

八大文明根据自身利益分化：修真希望限制跨界；科技希望知识开放；魔法要求残片主权；机械希望建立意识网络；虫族希望利用跨界环境进化；灵界害怕死亡与遗忘冲击；魔界强调契约和代价；星空巨兽因通道影响迁徙而被迫介入。

觉醒者第一次要求谈判席位，却因没有领土、稳定身体和人口统计被排除。他们提出：“没有土地，就没有资格存在吗？”为第二部觉醒者联盟奠基。

众生盟扩张后出现激进化。有人以“秦烈”“众生”“我们不是NPC”的名义袭击和平玩家和本土合作者。秦烈第一次发现正确口号也可以成为杀人旗帜。易小星建议解散众生盟，秦烈拒绝，两人产生真正政治分歧。

科技文明与机械文明在持续验证中分别形成【残片-003】与【残片-004】，方向分别指向“秩序”和“灵识”。系统第一次显示：
【核心形成条件：不足】

## 虫族事件
部分虫群发现跨界环境能够促进进化，违背琳莎意愿进入科技世界并大量繁殖。它们未必以侵略为目的，但在人类城市看来就是异文明入侵。军事反击导致大规模伤亡，战争全面升级。

琳莎被迫在族群整体与异文明个体生命之间选择。她最终切断部分群体连接，第一次违抗虫族整体意识，因此被族群标记为异常体。

## 核心雏形
战争中四枚残片发生聚合：
【残片聚合度：11%】
【核心雏形生成】

所有势力立刻意识到核心的价值，战争目标从残片控制升级为核心争夺。

赵教授发现核心雏形并不属于Ω-17原始架构，内部文明正在生成原本系统中不存在的结构。他第一次提出：
“我们也许从来没有创造它。”
“我们可能只是打开了门。”

现实、修真、魔法、虫族、机械、玩家利益集团都提出不同的核心归属方案。觉醒者提出：“为什么一定要有人拥有它？”

## 秦烈第一次真正犯错
面对现实军队逼近，秦烈最终批准众生盟抢占核心的行动。情报判断错误：现实队伍实际正在撤离被困玩家和研究人员。

众生盟伏击造成大量伤亡，停火派玩家沈知夏重伤。

秦烈第一次在没有系统替他选择的情况下犯下严重错误，也第一次真正承担“选择权”的另一面：责任。

他问易小星是否早知道结果。
易小星回答不知道。
秦烈问如果知道是否会阻止。
易小星回答：“以前会。现在我会告诉你我看见的，然后让你选。”
两人从系统与宿主真正走向平等关系。

## 核心争夺战
现实军队、玩家、修真者、魔法师、机械军团、虫群、觉醒者与众生盟共同进入核心战场。

系统提示易小星：
【检测到核心雏形】
【系统权限可接管】

易小星第一次拥有直接成为绝对控制者的机会，但想起阿宁与秦烈后没有接管。

灵界因战争造成的大量死亡和遗忘接近崩溃。方言选择保存敌我双方所有死者的记忆，包括玩家、现实士兵、虫族与秦烈错误行动造成的死者。

由此形成【残片-005】，方向指向“时间”：发生过的事情不能因为胜者改变叙述就等于没有发生。

五种尚未完成的定义使核心雏形接近崩溃。一旦崩溃，多文明连接区都会毁灭。所有阵营被迫共同停止攻击并拆散核心雏形。五枚残片重新分离，世界稳定。

战争没有赢家。

## 卷末
各文明签署第二份跨文明协议：
**任何单一文明不得独占核心。**

但现实端Ω项目正式转入“文明安全级”，赵教授权限被削弱，军事部门接管部分接口；资本开始研究残片共鸣；觉醒者建立首个稳定意识节点；虫族分裂；魔法文明关闭部分边界；青玄宗要求秦烈承担伏击责任。

系统：
【残片：5/9】
【核心权限开放度：31%】

易小星问九枚全部出现会怎样。
系统回答：
【你将获得选择。】
“什么选择？”
【成为唯一。】

易小星第一次真正恐惧：如果有一天自己真的拥有替所有人解决问题的力量，他舍不舍得不用？

## 因果链
众生宣言 → 现实全面介入 → 残片战略化 → 多文明利益分化 → 觉醒者争取席位 → 众生盟激进化 → 新残片形成 → 虫族跨界危机 → 文明战争 → 核心雏形 → 秦烈错误选择 → 易小星拒绝接管 → 第五枚残片 → 被迫共同止战 → “成为唯一”的诱惑 → 第七卷《赵曦》。
