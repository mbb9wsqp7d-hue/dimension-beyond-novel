# 第四墙与叙事战争旧版【历史废弃】

> 来源：早期第一部卷纲。此方案已被V5.0明确废弃，但完整保留其创作价值，后续可拆解为非元叙事剧情素材。

## 旧版核心
第一部后期曾设计“虚拟 → 虚构”的第四墙坍塌：
- 世界变成文字、稿纸与书页。
- 赵教授/作者影像掌握“作者之笔”。
- 九大核心被【设定不可更改】文字锁链束缚。
- 角色与玩家联合发动“叙事战争”。
- 读者弹幕、留言、支持与质疑可以改变战局。
- 九大文明武器化为“章节军团”。
- Ω协议拼合率一度达到120%。
- 易小星最终面对“归人 / 成神”二选一。

## 可回收的非元叙事内核
虽然“作者/读者/书页”机制废弃，但以下内核可以迁移：
1. 秦烈拒绝“被安排的命运” → 可转化为命运核心冲突。
2. 苏青破解无限重复事件 → 可转化为时间/数据回滚。
3. 韩越打破“机械无情”的身份标签 → 可转化为机械文明人格权。
4. 方言照见被删除意识 → 可转化为时墟中的废弃数据生命。
5. 契罗撕毁预定死亡命运 → 可转化为命运/熵能核心冲突。
6. 赵曦以情感锚定自我 → 可保留为主体性证明。
7. “归人 / 成神” → 保留为易小星终极伦理选择，但不再通过作者层实现。

## 当前裁决
【废弃】：作者层、读者层、弹幕意志、书页世界、章节兵器。
【保留母题】：反抗被定义、归人、选择权、有限生命比绝对神权更有意义。
